# bag → PCD + 2D 地图（固化流程 V1.0）

给一条 ROS1 bag，一条命令出**静态点云 PCD**和**2D 占据栅格地图**。不需要 ROS 运行时，不需要手工填参数。

- 入口：`tools/bag_to_map.py`
- 底层：`tools/bag_mapping_pipeline.py`（bag → PCD/轨迹）+ `tools/slope_map_projector.py`（PCD/轨迹 → 2D 图）
- 版本：2026-10-27 现场验收（scan_0 通过 / scan_1 拒绝）

## 用法

```bash
cd tron2_ws_backup
python3 tools/bag_to_map.py --bag <任意.bag> --out out/<跑次名>
```

依赖：`numpy`、`scipy`（系统 `/usr/bin/python3` 已满足）。**不需要 ROS**，Mac 上可直接跑。

## 固化参数（不接受逐次调参）

| 参数 | 值 | 取值理由 |
|---|---|---|
| 体素 | 0.05 m | 与 2D 图分辨率一致；再细只是重复点 |
| 帧数阈值 | **固定 3 帧** | 2026-10-27 现场对比拍板：2 帧杂点太多、4 帧丢细节（花坛边缘等矮结构），3 帧保留 37% 更多结构且仍干净 |
| 地面偏移 | 自动估计 | 轨迹附近点的相对高度主峰 = 地面；实测 1.17~1.18 m，与卷尺值 1.20 相差 <3 cm |
| 障碍窗 | **0.10 ~ 1.00 m**（相对当地地面） | 下沿 0.10 抓矮障碍；下沿取 0 会整片地面灌成障碍（实测 45,549 vs 17,103 格）。上沿 1.00 覆盖机器人能撞到的高度，再高会把桌面/人上半身当墙 |
| 栅格 | 0.05 m | 与 `map_server` 契约一致 |
| 轨迹分段 | 1.0 m 路径 / 0.10 m 高差 | 坡道上每段换一次地面基准；这是"不用一刀切"的关键 |
| 轨迹距离门限 | 8 m | 裁掉远场离群点 |
| 占据栅格化半径 | 0.05 m | 保证墙线连续 |
| 射线自由空间填充 | **开**（`--raycast-free`，跳过近端 0.20 m） | 从轨迹位姿向观测点连线，把经过的格子标可通行；走廊/房间内部成片变白，没去过的区域才留灰 |

改任何一个值都要同步本文件、并在 `BASELINE.md` 登记。

## 输出

| 文件 | 内容 |
|---|---|
| `cloud_voxel_all.pcd` | 全部 5 cm 体素，intensity = 被观测帧数（想换阈值不用重跑，按 intensity 过滤即可） |
| `cloud_static.pcd` | 过滤后的静态点云（送进投影的就是它） |
| `traj_camera_init.tum` | 轨迹（TUM 格式） |
| `map.pgm` / `map.yaml` | 2D 地图：**0=障碍，205=未知，254=可通行**；直接可被 `map_server` 读 |
| `metrics.json` | 自动估计值、帧数分布、判据 |
| `map_metrics.json` | 投影参数与分段明细 |
| `summary.json` | 本次运行汇总 |
| `report.md` | 人读的体检结论 |

## 轨迹体检（会自动拒绝出图）

出图前检查里程计是否发散，任一条不满足即停止（`--force` 可强制）：

| 门限 | 健康值参考 |
|---|---|
| 相邻位姿最大位移 ≤ **1.0 m** | scan_0 实测 0.061 m |
| 全程高差 ≤ **5.0 m** | scan_0 实测 0.716 m |
| 时长 ≥ **10 s** | — |

拒绝样例（scan_1.bag，3 秒内报错）：

```
相邻位姿最大位移 23.09 m > 1.0 m（里程计疑似发散）
全程高差 173653.08 m > 5.0 m（里程计疑似发散）
```

> scan_1 的发散原因已定位：第 100 秒出现 5~7g 物理冲击（|a| 最大 68 m/s²，680 次超 30），
> 之后 z 一路积分到 -173 km。雷达/IMU 数据率与点数全程正常，不是掉线。

## 已知限制

1. 只处理 ROS1 bag（v2.0），支持 none/bz2 压缩；lz4 需装 `python-lz4`。
2. 没有 `/Odometry` 的 bag 无法走本流程（没有轨迹就没有逐段地面基准）。
3. `/cloud_registered` 若被 `dense_publish_en=false` 降采样，墙会偏细、有断点——这是源头问题，不是本流程的。
4. 帧计数过滤只能去"停留时间短"的动态物；长时间静止的人需要射线穿透投票或换趟比对。
5. 输出图是"障碍/未知/可通行"三态，没有做射线自由空间裁剪，不是完整 SLAM 地图。
